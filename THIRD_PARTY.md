# Source and dependency review

Source is owner-directed IMCrypto baseline in MIGRATION_SOURCE.toml. Imported
files include no vendored third-party code. Cargo.lock pins registry sources.
Source metadata is Proprietary and is preserved, not relicensed.

Production primitives are from RustCrypto, dalek, rand_core and zeroize;
the optional SQLCipher reference store uses rusqlite/libsqlite3-sys and
vendored OpenSSL through Cargo. SM crates are development-only spikes, not
a product cipher-suite support claim. Native SQLCipher/OpenSSL/SQLite
licenses and notices must be bundled and checked before binary distribution.

The dependency inventory is generated by scripts/verify.sh. SPDX metadata
is useful inventory, not legal advice or a complete license compliance audit.
No package or binary release is authorized by this source migration.
